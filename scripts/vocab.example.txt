# ============================================================
# 課堂常用語（強烈建議加入）
# ============================================================
# 課堂錄影裡最常被聽錯的不是教材詞，而是教師的口頭指令與課堂慣用語。
# 實例：「專件字」其實是「關鍵字」、「誰在高度啊」是「誰可以告訴我」、
#       「就減爪」是「就減短」、「差不多久了」是「差不多九成了」。
# 這些字面上都不通，但只要放進課堂語境就一眼看得出來。
